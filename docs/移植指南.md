# SpinMFC 项目移植指南

## 发送前准备（发送者）

1. 压缩前删除以下目录，可大幅减小体积并避免携带本地缓存信息：
   - `.vs/`（VS 用户缓存）
   - `x64/`（编译输出文件）

2. 将整个 `SpinMFC` 文件夹压缩为 `.zip` 文件发送。

## 安装

1. 下载 `SpinMFC.zip` 压缩包，解压到任意文件夹
2. 打开 `SpinMFC.sln`，使用 **Visual Studio 2022** 打开

> 如果使用 **VS2019 或 VS2017**：打开后 VS 会自动弹出"重定目标"对话框，点确定即可（VS 会自动转换平台工具集）

## 编译前配置

### 第一步：选择正确的平台和配置

在 VS 工具栏顶部：
- **解决方案配置**：选择 **Debug**
- **解决方案平台**：选择 **x64**

> 项目中的 Spinnaker SDK 路径只配置了 Debug|x64，其他配置需要自行补充

### 第二步：配置 MFC 和字符集

右键项目 → 属性：

| 设置项 | 位置 | 值 |
|---|---|---|
| MFC 的使用 | 配置属性 → 高级 → MFC 的使用 | 在共享 DLL 中使用 MFC |
| 字符集 | 配置属性 → 常规 → 字符集 | 使用 Unicode 字符集 |

### 第三步：配置 Spinnaker SDK 包含目录

**配置属性 → VC++ 目录 → 包含目录**，添加以下路径（替换为你的实际安装路径）：

```
D:\SpinnakerSDK\你的版本\include
D:\SpinnakerSDK\你的版本\include\GUI
D:\SpinnakerSDK\你的版本\include\Interface
D:\SpinnakerSDK\你的版本\include\spinc
D:\SpinnakerSDK\你的版本\include\SpinGenApi
```

### 第四步：配置 Spinnaker SDK 库目录

**配置属性 → VC++ 目录 → 库目录**，添加以下路径：

```
D:\SpinnakerSDK\你的版本\lib64\vs2015
D:\SpinnakerSDK\你的版本\lib64\vs2017
```

### 第五步：配置链接器附加依赖项

**配置属性 → 链接器 → 输入 → 附加依赖项**，添加：

```
Spinnaker_v140.lib
SpinVideo_v140.lib
strmiids.lib
uuid.lib
```

> 如果报错找不到 `.lib` 文件，改用绝对路径，例如：
> `D:\SpinnakerSDK\你的版本\lib64\vs2015\Spinnaker_v140.lib`

### 第六步（可选）：Windows SDK 版本

如果打开时报错"Windows SDK 版本不匹配"：
- 项目属性 → 配置属性 → 常规 → **Windows SDK 版本**，下拉选择一个可用的版本即可

## 项目关键配置参考（Debug|x64）

| 配置项 | 值 |
|---|---|
| 平台工具集 | v143 (VS2022) |
| MFC 使用 | 在共享 DLL 中使用 MFC |
| 字符集 | 使用 Unicode 字符集 |
| 包含目录 | Spinnaker SDK 的 `include` 及子目录 |
| 库目录 | Spinnaker SDK 的 `lib64\vs2015`、`lib64\vs2017` |
| 附加依赖项 | `Spinnaker_v140.lib`、`SpinVideo_v140.lib`、`strmiids.lib`、`uuid.lib` |

## 安装 MFC 组件（如编译时报错 MFC 相关缺失）

1. 打开 Visual Studio Installer（`VisualStudioSetup.exe`）
2. 点击已安装的 VS2022 右侧的 **修改**
3. 切换到 **单个组件** 选项卡
4. 找到 **SDK、库和框架** 分类，勾选：
   - **适用于最新 v143 生成工具的 C++ MFC (x86 和 x64)**
5. 点击 **修改**，等待安装完成
6. 重新打开项目编译即可
